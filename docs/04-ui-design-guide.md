# PM SOP UI 设计指南

> 版本：v1.0.0 ｜ 最后更新：2026-08-05 ｜ 设计语言：现代极简（Notion/Linear 风）

---

## 1. 设计语言

- **原则**：内容优先、留白充足、层次清晰、低视觉噪音
- **气质**：专业、克制、高效，类似 Notion 的清爽 + Linear 的精致
- **密度**：中等信息密度，桌面优先，移动端降密度自适应

---

## 2. 色彩系统

### 2.1 品牌与主色

| Token | 值 | 用途 |
|-------|-----|------|
| Primary | `#3B82F6` (Blue-500) | 主操作、链接、激活态 |
| Secondary | `#6366F1` (Indigo-500) | 辅助强调 |
| Background | `#F8FAFC` (Slate-50) | 页面底色 |
| Surface | `#FFFFFF` | 卡片/面板 |
| Border | `#E2E8F0` (Slate-200) | 分隔线/边框 |

### 2.2 文本

| Token | 值 | 用途 |
|-------|-----|------|
| Text Primary | `#0F172A` (Slate-900) | 标题/正文 |
| Text Secondary | `#475569` (Slate-600) | 次要文字 |
| Text Tertiary | `#94A3B8` (Slate-400) | 占位/禁用 |

### 2.3 语义色

| Token | 值 | 用途 |
|-------|-----|------|

### 2.4 暗色模式（自动反相）

## 6. 阴影系统

- `shadow-sm`：卡片静态
- `shadow-md`：悬浮卡片/下拉

## 8. 组件规范

### 8.1 按钮 Button
- 变体：`primary` / `secondary` / `ghost` / `danger`
- 尺寸：`sm` / `md` / `lg`
- 图标按钮：方形 `aspect-square`

### 8.2 徽章 Badge / 标签 Tag
- Badge：状态/优先级（带背景色）
- Tag：可删除标签（需求/任务标签）

### 8.3 表格 Table
- 斑马纹关闭，行间 `border-b` 分隔
- 表头 `text-xs uppercase text-tertiary`
- 行 hover 高亮

### 8.4 弹窗 Modal
- `rounded-xl shadow-lg`，遮罩 `bg-black/40 backdrop-blur-sm`
- 居中，移动端贴近底部

### 8.5 空状态 EmptyState
- 居中图标 + 标题 + 描述 + 操作按钮

### 8.6 骨架屏 Skeleton
- `animate-pulse bg-slate-200 rounded`

### 8.7 项目切换器 ProjectSwitcher（v2 新增）
- **桌面端**：侧边栏顶部固定下拉框，显示当前项目名 + 标识色圆点
  - 点击展开下拉列表：已有项目列表 + 「新建项目」按钮
  - 切换后全局 `activeProjectId` 变化，各模块列表刷新
- **移动端**：顶部标题栏左侧项目名，点击弹出底部抽屉选择器
- **空项目状态**：首次无项目 → 显示引导卡片「您还没有项目，请先创建」+ 创建按钮

### 8.8 PRD 模板新建流程（v2 新增）
- **步骤 1 — 选模板**：卡片网格展示预设模板（如「标准 PRD 模板」），点击进入
- **步骤 2 — 逐节点填写**：
  - 左侧节点树（5 个节点顺序排列）：已完成的打勾、当前高亮、未开始的灰色
  - 右侧编辑器：当前节点的 Tiptap 富文本编辑区，顶部提示文字
  - 底部导航：上一步 / 下一步 / 跳过
- **步骤 3 — 预览 & 保存**：拼接所有节点内容为完整 PRD，只读预览
- **操作栏浮底**：保存草稿（回列表）/ 上传到云端 / 取消

│         │  [StatsCard][StatsCard][StatsCard][St]│

│         │  │ 最近需求    │ │ 任务进度          │  │
