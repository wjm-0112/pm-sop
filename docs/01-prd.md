> 版本：v1.0.0 ｜ 状态：规划中 ｜ 最后更新：2026-08-05

## 1. 产品概述

### 1.1 项目背景

产品经理在日常工作中需要遵循一套标准化的作业流程（SOP），涵盖需求管理、产品规划、项目推进、竞品与市场分析四大核心环节。然而当前这些工作往往分散在多个工具（飞书文档、TAPD、Excel、思维导图等）中，存在以下痛点：

- **信息孤岛**：需求、版本、任务、竞品数据割裂，难以形成闭环追溯
- **流程不标准**：缺乏统一的状态机与模板，不同项目执行口径不一致
- **离线不可用**：依赖在线协作工具，网络受限时无法查看/编辑
- **数据难沉淀**：个人方法论与历史决策散落各处，难以复用

### 1.2 目标用户

| 维度 | 说明 |
|------|------|
| 角色 | 产品经理（B 端/数据平台方向为主） |
| 典型画像 | 负责材料数据平台等复杂系统的专业 PM |
| 使用场景 | 桌面办公（主力）+ 移动端随时查看（辅助） |
| 协作模式 | 单用户个人工作台为主，预留多用户扩展 |

### 1.3 核心价值主张

> **一个贯穿产品经理完整 SOP 的本地优先工作台：从需求到上线，全流程可追溯、可沉淀、可离线。**

- **全流程贯通**：四大模块数据相互关联，需求→版本→任务→风险形成闭环
- **标准化模板**：内置 PM 方法论框架（状态机、PRD 模板、风险矩阵等）
- **本地优先 + 离线**：数据存于浏览器本地，无需联网即可使用
- **多端一致**：响应式 Web + PWA，桌面与移动端体验统一

### 1.4 成功指标

| 指标 | 目标值 |
|------|--------|
| 首屏加载耗时 | < 3s（PWA 缓存后 < 1s） |
| 本地数据操作延迟 | < 100ms |
| 单设备数据容量 | 支持 ≥ 10,000 条记录流畅操作 |
| 离线可用率 | 100%（静态资源 + 本地数据） |

## 2. 功能需求

### 2.0 多项目管理（v2 新增）

作为顶层容器，将需求/版本/PRD/任务/竞品等按项目维度隔离。

#### 2.0.1 项目实体
- 项目 CRUD：名称、描述、状态（active / paused / completed）、标识色
- 侧边栏顶部**项目切换器**：下拉选择当前项目，桌面端常驻、移动端顶部栏切换
- 首次使用无项目 → 引导创建"您还没有项目，请先创建"
- 所有业务实体（需求、版本、PRD、任务、里程碑、风险、竞品、市场调研、用户画像）关联 `projectId`

#### 2.0.2 项目内导航
- 切换项目后，只显示当前项目下的数据
- 跨项目数据完全隔离（通过 `projectId` 索引过滤）

---

### 2.1 模块一：需求管理全流程

贯穿需求从产生到关闭的完整生命周期。

#### 2.1.1 需求录入
- 支持新建需求，字段含：标题、描述（富文本）、类型、优先级、来源、负责人、审核人、标签、附件、截止日期、预估工作量、业务价值评分
- 支持标签多选输入（TagInput）
- 支持附件上传（文件/链接/图片，以 base64 存于本地）

#### 2.1.2 分类与优先级
- 类型：`feature` / `bug` / `optimization` / `technical`
- 优先级：`P0` / `P1` / `P2` / `P3`
- 来源：`user` / `internal` / `competitive` / `market` / `leadership`

#### 2.1.3 状态流转（状态机）
```
草稿(draft) → 评审中(reviewing) → 已通过(approved) → 已实现(implemented) → 已关闭(closed)
                    ↓
                已拒绝(rejected) → 已关闭(closed)
```
- 状态切换时记录变更日志（谁、何时、为何）
- 可视化状态流转图

#### 2.1.4 需求分解
- 支持父子需求关系（parentId），形成需求树
- 子需求可逐级拆解

#### 2.1.5 变更管理
- 编辑需求时自动对比字段差异，生成变更日志（ChangeLog）
- 每条变更记录：字段、旧值、新值、变更人、变更时间、原因

#### 2.1.6 列表与检索
- 表格视图 / 网格视图切换
- 高级筛选：状态、优先级、类型、来源、负责人、标签、日期范围
- 关键词搜索
- 分页（每页 50 条）

---

### 2.2 模块二：产品规划与设计

将需求转化为可执行的产品规划。

#### 2.2.1 产品路线图
- 时间线视图，按季度/月份展示版本节奏
- 版本卡片展示：名称、状态、起止时间、目标

#### 2.2.2 版本管理
- 版本 CRUD：版本号（如 v2.1.0）、名称、描述、状态、起止时间、目标列表
- 状态：`planned` / `in_progress` / `released` / `cancelled`
- 版本关联需求（版本需求分配，拖拽分配）

#### 2.2.3 PRD 撰写
- 基于**节点模板**逐步填写：选择模板 → 按节点填写内容 → 预览 → 保存
- 预设「标准 PRD 模板」包含 5 个节点：背景与目标、目标用户、核心功能列表、非功能需求、验收标准
- 每个节点独立填写，拼接生成完整 PRD
- 集成 TipTap 富文本编辑器，支持标题、列表、表格、任务清单、图片、引用等
- PRD 状态：`draft` / `review` / `approved` / `archived`
- 关联需求与版本
- 操作栏：保存草稿 / 上传到云端 / 取消

#### 2.2.4 PRD 预览
- 只读模式预览，支持打印/导出

---

### 2.3 模块三：项目推进与跟踪

将规划落地为可跟踪的执行过程。

#### 2.3.1 看板视图（核心）
- 5 列：Backlog / Todo / In Progress / Review / Done
- 卡片拖拽：列间移动、列内排序（基于 @dnd-kit）
- 在看板内快速新建/编辑任务

#### 2.3.2 任务管理
- 任务 CRUD，字段含：标题、描述、状态、优先级、负责人、关联需求/版本/里程碑、故事点、预估/实际工时、依赖、截止日期
- 任务列表视图（表格）
- 任务详情页

#### 2.3.3 里程碑追踪
- 里程碑 CRUD：标题、描述、截止日期、状态、关联版本、交付物清单
- 时间线视图展示里程碑节奏
- 状态：`pending` / `in_progress` / `completed` / `delayed`

#### 2.3.4 风险管控
- 风险 CRUD：标题、描述、类别、概率、影响、状态、缓解措施、应急预案、负责人
- 概率 × 影响 二维风险矩阵（气泡图可视化）
- 颜色编码风险等级（低/中/高/严重）

---

### 2.4 模块四：竞品与市场分析

支撑产品决策的市场情报模块。

#### 2.4.1 竞品分析
- 竞品 CRUD：名称、Logo、描述、网站、类型（直接/间接/潜在）、优劣势、功能评分、市场份额、目标用户、定价、融资阶段
- 竞品对比矩阵：功能项为纵轴，竞品为横轴，评分可视化
- 功能对比雷达图（Recharts）

#### 2.4.2 市场调研
- 调研记录 CRUD：标题、内容（富文本）、分类、来源、关键发现、标签、附件
- 按分类与时间组织

#### 2.4.3 用户画像
- 画像 CRUD：姓名、角色、头像、人口统计、目标、痛点、行为、动机、场景、原话
- 画像卡片可视化展示

#### 2.4.4 用户旅程地图
- 旅程阶段管理：阶段名、用户行为、想法、情绪、痛点、机会点、接触点
- 纵向阶段展示，情绪以颜色标注

## 3. 非功能需求

| 类别 | 需求 |
|------|------|
| 离线可用 | 所有数据存于 IndexedDB，离线可完整 CRUD；静态资源由 Service Worker 预缓存 |
| PWA 可安装 | 支持桌面/移动端"添加到主屏幕"，standalone 全屏模式 |
| 数据导出 | 支持 JSON（全量/模块/筛选）、CSV、Excel（多 Sheet） |
| 数据导入 | JSON 导入，支持全量替换/合并/追加三种策略，导入前预览校验 |
| 响应式设计 | 桌面侧边栏 + 移动端底部 Tab；断点 sm/md/lg/xl |
| 性能 | 首屏 < 3s，数据操作 < 100ms，大数据量虚拟滚动 |
| 主题 | 亮色 / 暗色 / 跟随系统 |
| 安全 | 数据不出本地；外链 `rel="noopener noreferrer"`；富文本 XSS 过滤；云端同步数据端到端加密（PBKDF2+AES-GCM） |
| 云端同步 | 支持通过 GitHub PAT 将加密备份同步到远程仓库，跨设备拉取；密码仅 session 内存，令牌仅作传输凭证 |
| 可扩展 | 预留多用户/后端同步架构（ownerId、API Route 骨架） |

## 5. 验收标准

### 5.1 需求管理
- [ ] 可新建/编辑/删除需求，所有字段正确保存
- [ ] 状态流转触发变更日志自动记录
- [ ] 高级筛选与搜索结果准确，分页正常
- [ ] 父子需求关系正确建立与展示

### 5.2 产品规划
- [ ] 路线图时间线正确渲染版本
- [ ] PRD 编辑器支持富文本且保存/重载内容一致
- [ ] 版本可关联/取消关联需求

### 5.3 项目推进
- [ ] 看板 5 列拖拽流畅，状态变更即时持久化
- [ ] 里程碑时间线与状态正确
- [ ] 风险矩阵气泡位置与颜色符合概率×影响

### 5.4 竞品分析
- [ ] 竞品对比矩阵与雷达图数据一致
- [ ] 用户画像与旅程地图完整可编辑

### 5.5 通用
- [ ] JSON/CSV/Excel 导出文件可被对应软件正确打开
- [ ] JSON 导入三种策略行为正确
- [ ] 离线刷新后可正常操作
- [ ] 移动端布局无错位，PWA 可安装

## 6. 范围与边界

**包含（In Scope）：**
- 单用户本地优先工作台
- 四大模块完整 CRUD 与关联
- 数据导入导出
- PWA 安装与离线

**不包含（Out of Scope，v1.0）：**
- 多用户实时协作
- 后端服务（双向同步服务器）
- 第三方平台集成（飞书/TAPD 双向同步）
- 高级权限与审计

> 上述 Out of Scope 内容已在架构层预留扩展接口，可作为后续版本迭代方向。
