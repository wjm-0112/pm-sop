## 1. 产品概述

### 1.1 项目背景

产品经理在日常工作中产出了大量有价值的产出物（PRD 文档、原型设计、项目复盘等），但这些产出往往分散在多个平台（飞书文档、Figma、本地文件等），缺乏一个集中展示与回顾的入口。在面对面试、述职、内部分享等场景时，难以快速、专业地呈现过往成果。

### 1.2 目标用户

| 维度 | 说明 |
|------|------|
| 角色 | 产品经理（B 端方向为主） |
| 典型画像 | 5 年+ B 端 SaaS 产品经验的专业 PM |
| 使用场景 | 个人作品回顾 + 向他人展示（面试/述职/分享） |
| 协作模式 | 单人所有（数据维护）+ 访客浏览 |

### 1.3 核心价值主张

> **一个产品经理专属的作品集展示站：集中管理、多维浏览、专业呈现。**

- **集中管理**：PRD / 原型 / 复盘 三大类作品统一收纳
- **多维浏览**：分类筛选、关键词搜索、时间线演进、精选展示
- **专业呈现**：结构化元数据 + Markdown 正文渲染，卡片式布局现代美观
- **易于维护**：管理后台支持在线编辑、文件上传、云端加密同步

### 1.4 成功指标

| 指标 | 目标值 |
|------|--------|
| 首屏加载耗时 | < 2s |
| 作品列表浏览 | 支持 50+ 作品流畅筛选 |
| Markdown 渲染 | 支持 GFM 完整语法（表格/代码/任务列表） |
| 响应式适配 | 手机/平板/桌面三端完美展示 |
| 管理后台可用性 | 支持全程在线编辑，无需手动改文件 |

## 2. 功能需求

### 2.1 前台展示（V1.0）

#### 2.1.1 个人主页（首页）
- 个人信息区块：头像、姓名、职称、一句话简介、技能标签（按类别分组）、工作经历（时间线）、联系方式
- 精选作品展示（featured=true 的作品卡片）
- "查看全部"跳转至作品列表页

#### 2.1.2 作品列表页
- 卡片网格布局（响应式 1/2/3 列）
- 分类筛选：全部 / PRD文档 / 原型设计 / 项目复盘
- 状态筛选：全部 / 已完成 / 草稿 / 已归档
- 关键词搜索：标题、摘要、标签
- 排序：最新优先 / 最早优先 / 标题 A-Z / 标题 Z-A
- 卡片内容：分类标签、标题、摘要（2行截断）、标签、创建日期

#### 2.1.3 作品详情页
- 面包屑导航：首页 > 作品列表 > 作品标题
- 元数据展示：分类 + 状态徽章、标题、摘要、日期、标签
- Markdown 正文渲染（react-markdown + remark-gfm）
- 附件链接（如有）

#### 2.1.4 时间线视图
- 按创建年份自动分组
- 时间线节点：年份标注 + 蓝色圆点 + 连接线 + 作品条目
- 点击条目跳转至详情页

### 2.2 管理后台（V2.0）

#### 2.2.1 布局
- 若依框架风格：左侧菜单 + 顶部面包屑 + 右侧内容区
- 菜单项：仪表盘 / 个人资料 / 作品管理 / 文件管理 / 云同步
- 支持侧边栏折叠
- "返回前台"快捷入口

#### 2.2.2 仪表盘
- 统计卡片：作品总数 / PRD数量 / 原型数量 / 复盘数量
- 最近更新表格（显示标题、分类、状态、更新时间，支持快速跳转编辑）

#### 2.2.3 个人资料管理
- 标签页编辑：基本信息 / 技能标签 / 工作经历 / 联系方式
- 头像上传（支持 URL 输入 + 本地上传）
- 技能标签：名称、分类、水平（了解/掌握/熟练/精通）
- 工作经历：公司、职位、日期范围、描述，支持增删
- 联系方式：类型（邮箱/微信/GitHub等）、值、标签、是否公开

#### 2.2.4 作品管理
- 作品表格列表（标题、分类、状态、精选标记、日期）
- 新增/编辑作品元数据（分类、状态、标签、精选标记）
- Markdown 在线编辑器（@uiw/react-md-editor，分屏实时预览）
- 封面图上传与管理
- 删除作品（软删除 → 归档）

#### 2.2.5 文件管理
- 文件上传（multer 后端处理，最大 50MB）
- 文件列表浏览（文件名、大小、上传时间、预览）
- 复制文件 URL 供 Markdown 引用
- 图片文件缩略图预览

#### 2.2.6 云同步
- GitHub Token + 仓库配置
- AES 端到端加密
- 一键加密推送至 GitHub 仓库
- 一键从 GitHub 拉取并解密恢复
- 密码仅用于加解密，Token 仅作传输凭证

## 3. 非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | 首屏 < 2s（Vite 构建 + gzip 压缩），路由切换流畅 |
| 类型安全 | TypeScript 全覆盖，编译零错误 |
| 可维护性 | 组件化架构、数据与视图分离、CSS Variables 设计令牌 |
| 可扩展性 | 预留 metadata 扩展字段、嵌套路由、主题切换接口 |
| 响应式 | Mobile First 设计，三档断点（<640 / 640-1024 / >1024） |
| 浏览器兼容 | Chrome / Firefox / Safari / Edge 最新两个版本 |
| 数据安全 | 本地 JSON 文件存储、云同步数据端到端加密 |

## 6. 范围与边界

**包含（In Scope）：**
- 前台 4 个页面（首页 / 作品列表 / 作品详情 / 时间线）
- 管理后台 6 个页面（仪表盘 / 个人资料 / 作品管理 / 作品编辑 / 文件管理 / 云同步）
- Express 后端 API + 文件上传
- GitHub 加密云同步

**不包含（Out of Scope，v2.0）：**
- 多用户协作
- 深度 SEO（SSR）
- 第三方平台自动同步
- 访问统计与埋点

> 上述内容已在架构层预留扩展接口，可作为后续版本迭代方向。
